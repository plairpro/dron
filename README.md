# Дрон

Браузерная 3D-игра о защищённом инспекционном дроне.

Исходники игры находятся в этой папке. Дальнейшие изменения вносить здесь.
GitHub Pages: https://plairpro.github.io/dron/

## Локальный запуск

Из корня репозитория: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
Нужен браузер с WebGL. Сборка и установка зависимостей не требуются.

## Файлы

- `index.html`, `style.css`: интерфейс и оформление.
- `game.js`: 3D-сцена, освещение, дрон, препятствия, звук, управление.
- `physics.mjs`: полёт и столкновения.
- `lidar-ray.mjs`: пересечения лучей сканирования с геометрией камней.
- `three.module.js`: локальная копия Three.js r170, лицензия MIT в `THREE-LICENSE.txt`.
- `drone-icon.png`: предоставленная владельцем проекта иконка для кнопок и favicon.

Удержание пробела, A (Ф) или экрана поднимает дрон; отпускание снижает его.
Три столкновения завершают полёт. Очки равны пройденным метрам.

## Заряд и особые препятствия

Заряд: три бара, один расходуется на каждой сотне метров. Подвесная батарейка появляется каждые 85–115 метров и возвращает один бар (не выше трёх). При нуле дрон падает и дымится.

Надломленные сталактиты и красноватые бешеные мыши предупреждают дрожью 0,75 секунды. Камни падают, мыши взлетают. Особые препятствия разнесены минимум на 30 метров; вокруг батареек оставлены свободные участки.

На телефонах используются облегчённые материалы, меньше источников света и адаптивное разрешение. Удержание экрана не вызывает выделение текста.

Бешеная мышь гарантированно появляется в начале маршрута примерно после 60 метров, следующие — через 65–95 метров (с поправкой на свободное место). Красные отметки на падающих камнях удалены.
